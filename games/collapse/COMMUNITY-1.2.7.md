# v1.2.7　政策效果、事件选项和组阁说明

适配 Steam Windows 构建 24949409。已安装旧版的玩家退出游戏后，直接运行新版安装程序即可。

## 西方基金会

自由党掌管文体与教育部时，部门预算和效率都达到 75 即可开启。开启时不扣 75。政策开启后，每月按下表结算。

| 对象 | 变化 |
| --- | --- |
| 每个地区的贫困阶层激进度 | 不变 |
| 每个地区的中间阶层激进度 | −0.7 |
| 每个地区的精英阶层激进度 | −0.2 |
| 文体与教育部预算、效率 | 预算 −50，效率 −0.5 |
| 对俄罗斯、对美国的依附度 | 各 +0.5 |

原版英俄手册都把贫困阶层写进了同一政策的相反效果。此次用同一游戏状态分别开启和关闭政策，比较五个地区下一次结算的差值。按钮悬停列出五地合计，中间阶层为 −3.5，精英阶层为 −1.0。刚好满足两项门槛时可以开启，预算 74 或效率 74.9 时均无法开启。

## 其他校对

- 七个政党的手册对照各自的行动和修正效果。自1992年4月起，蓝衣社掌握总统、总理或外交部长职位时，对俄关系越差，其部门每月损失的预算越多。旧手册把它写成了收入。
- 事件中修正了把中国国家主席写成教会主席、把俄罗斯写成美国、把独联体写成俄罗斯等错误。美俄合作研制火星车的两个选择重新对齐。全国形势报告恢复了东部地区标题。
- 组阁手册改用“部长职位”，并区分轮流选任与联合组阁。西方基金会、维谢格拉德基金和农业部门的种质资源库按各自的用途命名。
- 三项竞选承诺说明统一显示现值与目标值的单位，明确目标是降至上限或以下。各地区的犯罪、腐败和阶层报告标出上期全国平均值、结算时间及城市化门槛。
- “企业发展”的悬停提示按游戏的实际结算显示地区执政党与全国卡特尔协会关系的增量。
- 我党没有主导派别、盟党有主导派别时，提示分别显示盟党收到的资金和盟党辖区的阶层变化。盟党收到资助后，党内资金和行政资源都大于零，当地贫困阶层的需求满足度才会额外提高。

## 验证范围

逐行对齐 7 张表的英文、俄文、工坊中文与补丁生成的中文，共 13,850 行。相较 v1.2.6，实际生成文本变更 374 行，其中事件 169 行、界面 113 行、系统 87 行、其他文本 5 行。检查了动态字段、富文本配对、数值方向及专名线索，两个最终嵌入字重都能显示全部 3,285 个不同的可打印字符与断行空格。另用独立游戏副本核验安装、从 v1.2.6 升级、重复安装和还原后的文件哈希。实机复测集中在文体与教育部、西方基金会和相关界面，剧情与结局没有逐条游玩。
