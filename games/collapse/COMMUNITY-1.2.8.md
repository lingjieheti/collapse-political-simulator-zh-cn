# v1.2.8　人物效果、党派行动与结局

适配 Steam Windows 构建 24949409。进入统计页的人物面板，悬停在六项属性上，可以看到各个等级的中文效果。配偶、子女和好友的提示也按其处境显示。原先子女的职业栏把“没有职务”写作“无立场”，好友陷入丑闻写作“已妥协”，现分别显示为“尚未任职”和“卷入丑闻”。[人物面板修订前后对照](../../docs/personality-effects.webp)

## 游戏中的变更

- 事件涉及与工会联盟、共和国女权联盟、共和国爱国教会和反叛军结盟时，明确了谈判对象。七党突击搜查行动及后续报纸标题改为揭露各党隐藏的丑闻。
- 地区议员组织改选后，结果说明写明议席原属哪个党、改由哪个党取得。对七个政党的教会绝罚分别区分了选择和结果。
- 捷克斯洛伐克解体事件补回哈维尔辞职，以及解散联邦的法定日期。辞职前的斯洛伐克主权宣言发生在7月。千年虫、动画禁令、女权联盟谈判等报道和对白也按上下文重译。
- 限制赴俄务工、党纲入宪、部门预算与效率门槛等行动采用对应的中文名称。任职条件明确区分内务部、国防部和行政领导权，工坊模组制作界面从零进度到上传完成共用中文提示。
- 摩尔多瓦两种结局会根据俄国政局分别显示普京、伊柳欣、斯科科夫或列别德。此前非普京分支只能替换俄文或英文姓名。

## 覆盖与验收

| 核对对象 | 本次结果 |
| --- | --- |
| 七张文本表 | 官方英俄文、工坊中文及安装成品按行对齐。共 13,850 行，含原作预留空行。长文分窗进行语义比较，再人工复核重点剧情、结算条件、组织和人名。 |
| 成品差异 | 相对 v1.2.7 实际有 173 行变化：事件 120 行、界面 49 行、系统 2 行、人物卡 2 行。剩余三表为条件用语、制作人员及修正名称。 |
| 场景与程序 | 44 个 Unity 资源文件中盘点出 21 个场景、1,293 个 TextMesh 和 27 个 TextAsset。原版游戏程序集含 7,133 处字符串载入、1,452 个唯一字串。定点补译 56 处，另补上模组制作页面初始状态。 |
| 原生显示 | 独立 Unity 运行 21 个场景。人物属性、配偶、子女与好友共检查 320 个中俄文状态组合。两种摩尔多瓦结局各验四位领导人。另在游戏中打开 53 个手册条目，核查正文与所附示范。 |
| 字体与安装 | 两个字重均覆盖最终七表实际使用的 3,284 种可打印字符，全库格式检查通过。安装器在本机原件副本中可完成旧版升级、重复安装、还原及重新安装。 |

手册的可滚动正文是中文。原版另有 34 段录像资源，按所用语言选择示范。中文版的 53 个手册条目中，15 项显示录像、28 项显示插图。录像画面及部分插图内仍能看到录制时的外文界面。片尾的开发者署名、音乐作者和链接保留原写法。Steam 为本作单列的附加内容是原声带。[Steam 游戏页](https://store.steampowered.com/app/990260/Collapse_A_Political_Simulator/)

从仓库根目录运行 `python -B -X utf8 tools/check_release.py` 和 `python -B -X utf8 -m unittest discover -s games/collapse` 可复核公开差分。开发者另可在装有正版游戏及工坊底包的电脑上运行 `python -B -X utf8 games/collapse/audit.py`，重做四栏全库检查。

开发环境安装 UnityPy 后，运行 `python -B -X utf8 tools/scan_unity_text.py` 可只读列出场景、文本、录像、纹理和精灵图数量。工具也接受 `--game-dir` 指定已有副本。玩家安装补丁使用内置运行环境。
