# v1.2.5　新游戏选择页的首行裁切

在“开始新游戏”中选择保守共和党，白色介绍卡第一行“保守共和党支持由国家调控的”上半笔画原来会被水平裁掉。下方灰色剧本框第一行也受影响。两处的文本原点都落在遮罩上缘，已经伸过这条边界的笔画会消失。新版将文本起点下移并给“更多信息”按钮留出更多上下边距。[同一游戏画面的前后对照](../../docs/party-description.webp)

四个字的按钮标题在旧版完整窗口中就能显示。反馈的图片从按钮内部开始取景，截去了标题上部。正文的裁切在完整窗口中可以复现。

## 像素复测

在 Steam Windows x64 构建 24949409 的独立副本里，通过游戏原有的选择按钮逐一切换七个党派和八种剧本。用游戏相机保存当前帧，再在同一帧临时移开正文裁线、保存对照图。两张图片相减，即可查出每个文字像素是否曾被遮住。

| 分辨率 | v1.2.4 保守共和党首行被遮像素 | v1.2.5 被遮像素 | v1.2.5 按钮标题上／下留白 |
| --- | ---: | ---: | ---: |
| 1280 × 720 | 172 | 0 | 6／5 像素 |
| 1920 × 1080 | 521 | 0 | 8／7 像素 |
| 3840 × 2160 | 1,779 | 0 | 17／14 像素 |
| 1600 × 1200（4:3） | 379 | 0 | 9／8 像素 |

四种分辨率的全部 60 组党派与剧本说明都与各自的完整文字对照一致。原先在 1080p 下，默认剧本第一行也有 538 个像素落在裁线外。

## 滚动与重入

随游戏提供的七篇党派介绍很短，八篇剧本说明最多排为七行。另在测试副本把正文扩展为 24 行，通过两个面板原有的滚动位置检查顶部、中段、底部，再返回顶部。现在末行完整显示，党派正文留在五个人物按钮上方。四种分辨率滚回顶部时，两张画面逐像素相同。退出选择页再进入，标题和两块正文的位置一致。

从 v1.2.4 升级或在原版安装后，正式 EXE 均通过核验、重复安装与还原。12 份受管文件逐一核对 SHA-256，本次更新其中的开局场景和界面程序集。与 v1.2.4 比较，已有程序方法中仅两个开局滚动排版入口发生变化。
