# 《Collapse: A Political Simulator》简体中文补丁

适用于 Windows Steam **Build 24949409**（App 990260）。安装器用玩家本机的游戏和工坊汉化生成资源，收录 504 条按行校订的简体译文，并对整套中文文本处理断行和排版。字体使用仓库提供的 Nostal UI SC 常规与半粗两个字重。

## 安装与还原

1. 关闭游戏，保持拥有游戏的 Steam 客户端在线，安装 64 位 Python 3.9 或更新版本。
2. 在解压后的仓库根目录打开终端，运行下面的命令。若工坊底包尚未安装，安装器向 Steam 请求临时缓存，不会更改订阅。

```powershell
py -3 games/collapse/collapse.py install
```

3. 从 Steam 启动游戏。补丁使用游戏的 **English** 语言槽。若之前在游戏内启用过工坊语言模组，请将其停用，返回主菜单，再重启游戏。主菜单会显示“开始新游戏”和“读取存档”。

校验当前安装或还原原始文件：

```powershell
py -3 games/collapse/collapse.py check
py -3 games/collapse/collapse.py restore
```

自动定位失败时，用 `--game "游戏文件夹"` 指定安装目录。底包已另存时，用 `--workshop "含 gui_text.txt 的工坊物品文件夹"` 指定来源。字体放在仓库根目录的 `fonts` 内，也可用 `--fonts "字体文件夹"` 指定。还原仅使用游戏目录 `.collapse-zh-24949409` 下的备份，不需要工坊在线。

安装器核对游戏、字体和工坊源文本的 SHA-256 后写入，并保留原件。Steam 更新或其他模组改动文件后，若校验值改变，安装器会停止。若工坊临时缓存被 Steam 回收，可从对应工坊页重新获取，再执行校验。存档独立于这些文件。

共 13,850 行。504 条人工逐项修订见 `revisions.tsv`。其余改动包括按英文原表核对的术语规则、模板及颜色标签修复、数字与缩写排版，以及中文词组断行。在验收用 Windows 环境上，有 12,860 行文本与底包的字节内容不同，其中包含标点与空格调整。这个数量不代表逐句重译。

七党的开局简介逐条对照英俄原文重译。中文词间的换行空格使用 0.080 em 字宽，并保留游戏的断行功能。英文及西里尔姓名中的词间距保持两个字重原有的 0.224 / 0.226 em。开局的两块说明框使用常规字重，字形相对原场景缩小约 14%，行距系数由 1.00 调整为 1.15，并为框内文字留出横向边距。画质档位显示“标准”，游戏仍按原有索引保存和应用设置。

本轮对照英俄原文及工坊译文，逐项修正 318 条，包含 48 条超过 500 个英文字符的长事件。详细行号、机制核验和可复跑命令见[文本复核记录](AUDIT.md)。

## 验证和覆盖边界

针对该构建，已独立解析七个 Unity 文本资源，复核条目数、富文本标签配对、复合格式花括号、英文原文中编号大于零的动态字段集合。游戏同时用 `{0}` 表示换行和部分动态值，对这两种用途按上下文处理。译文有 3,284 个不同的可打印字符，与 21 个场景的 TextMesh 文字合计 3,321 个，最终嵌入的两个字体均全部覆盖。已测试重复安装、写入中断回滚、遇到其他补丁时中止，以及五个文件完整还原。

此版本以原游戏的文本表为覆盖范围。未逐条触发全部剧本和结局。图片内嵌文字、其他玩家模组、新版游戏或新版工坊底包须另行适配。
