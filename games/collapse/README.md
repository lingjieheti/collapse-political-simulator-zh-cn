# 《Collapse: A Political Simulator》简体中文补丁

适用于 Windows Steam **Build 24949409**（App 990260）。安装器用玩家本机的游戏和工坊汉化生成资源，收录 708 条按行校订的简体译文，并对整套中文文本处理断行和排版。字体使用仓库提供的 Nostal UI SC 常规与半粗两个字重。

## 安装与还原

1. 从本游戏的发行页下载文件名以 `-Setup.exe` 结尾的 Windows 安装器。安装器内含运行环境。[下载独立安装器](https://github.com/lingjieheti/collapse-political-simulator-zh-cn/releases/latest)
2. 关闭游戏，双击安装器，选择安装。它会定位 Steam 游戏目录，再从已经安装的底包或其他已登记的 Steam 库获取中文文本。首次获取工坊底包时，请让拥有游戏的 Steam 账号保持登录并联网。
3. 从 Steam 启动游戏。打开设置，语言一项选择 **简体中文**。若之前在游戏内启用过工坊语言模组，请将其停用，返回主菜单，再重启游戏。主菜单会显示“开始新游戏”和“读取存档”。

普通与背景故事存档列表按字形宽度显示名称。点击带省略号的行，列表底部会显示完整名称。搜索仍可匹配完整名称，输入过长时会自动滚到最新输入的字符。

再次打开同一安装器即可校验或还原。已有旧版独立补丁或合集补丁时，安装器会沿用游戏目录内的原件备份。确认选择的游戏目录内含 `PoliticalSimulator.exe` 和 `PoliticalSimulator_Data`。

## 从源码运行

在源码根目录用 64 位 Python 3.12 运行以下命令。安装器使用标准库，无需另装 Python 软件包。

```powershell
py -3.12 games/collapse/collapse.py install
py -3.12 games/collapse/collapse.py check
py -3.12 games/collapse/collapse.py restore
```

手动指定游戏目录时可追加 `--game-dir "游戏文件夹"`。底包已另存时，用 `--workshop "含 gui_text.txt 的工坊物品文件夹"` 指定来源。字体放在仓库根目录的 `fonts` 内，也可用 `--fonts "字体文件夹"` 指定。

安装器核对游戏、字体和工坊源文本的 SHA-256 后写入，并保留原件。游戏目录下的 `.collapse-zh-24949409` 保存所有将修改的游戏原件以及本机已验证的七张工坊文本表，后续可以离线核验和还原。若 Steam 更新游戏或其他模组改动了相关文件，校验值改变时安装器会停止。存档独立于这些文件。

## 验证和覆盖边界

针对该构建，已独立解析七个 Unity 文本资源，复核条目数、富文本标签配对、复合格式花括号、英文原文中编号大于零的动态字段集合。游戏同时用 `{0}` 表示换行和部分动态值，对这两种用途按上下文处理。七张译表的可打印字符均已经两个最终嵌入字体回读核对。已测试重复安装、写入中断回滚、遇到其他补丁时中止，以及原件的完整还原。

此版本以原游戏的文本表为覆盖范围。未逐条触发全部剧本和结局。图片内嵌文字、其他玩家模组、新版游戏或新版工坊底包须另行适配。
